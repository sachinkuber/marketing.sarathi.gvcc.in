How connecting works

  1. Choose a platform and select Connect.
  2. The second-factor code is asked first. Enter the 6-digit code from your authenticator app.
  3. The platform's own screen opens. You sign in there and agree to the permissions it lists.
  4. You return here, and the account shows as connected with its permissions and expiry.
You sign in on the platform's own screen. No password is ever typed into this dashboard. If you cancel on the platform's screen, nothing changes and the account shows as Not connected.
